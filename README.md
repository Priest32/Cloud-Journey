# My Cloud Journey ☁️

I am starting this repository on **23 September 2026** to document my journey into cloud engineering.

## Where I Started

I began my cloud journey by learning and working hands-on with **Amazon Web Services (AWS)**.

So far, I have worked with:

- Cloud computing fundamentals
- IaaS, PaaS and SaaS
- Public, Private and Hybrid Cloud
- EC2, IAM, S3, EBS and EFS, RDS, DynamoDB
- VPC, Subnets and CIDR, Route Tables, Internet Gateway, NAT Gateway
- Security Groups, Network ACLs
- Lambda, CloudWatch, SNS and SQS
- Load Balancing, Auto Scaling
- AWS pricing and cost management
- AWS Shared Responsibility Model
- Cloud resource automation using Lambda
